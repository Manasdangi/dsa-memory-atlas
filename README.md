# DSA Memory Atlas

80 DSA interview problems grouped into 15 patterns, built to be remembered:

- **One picture per pattern** (hash map = locker room, sliding window = train window, BFS = ripples …)
- **A one-line story per problem** plus a short problem description and example
- **Step-by-step diagrams for every solution** — naive, optimised and best
- **195 commented C++ solutions** with time/space complexity, all compiled with `g++ -std=c++17` and tested (600 checks)

Live site: deployed on Vercel. Plain static site, no build step: `index.html` + `viz.js` + `viz-x.js` + `problems.json`.

Download every solution in one file: [`dsa_80_solutions_commented.cpp`](dsa_80_solutions_commented.cpp)
